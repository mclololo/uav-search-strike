## 五、同步策略

1. **src 代码**：使用 `tar + ssh + tar extract` 同步 `src/mission_pkg` 和 `src/object_det` 到 `/home/ubuntu/catkin_ws/src/`。
2. **model 文件**：使用 `scp` 逐个同步本地“云服务器上model文件夹里要改动的代码”中的文件到对应目标路径。
3. **不删除云端额外文件**：不使用 `--delete`，保留云端的 `basic_cn.txt`、`test_rflysim.py`、`FM9G4B-V/` 等。
4. **修复所有权**：同步完成后执行 `chown -R ubuntu:ubuntu /home/ubuntu/catkin_ws/src /home/ubuntu/model`。
5. **重新编译**：在云服务器执行 `cd /home/ubuntu/catkin_ws && catkin_make`。

---

## 六、注意事项

- 云服务器 SSH 连接使用 `root` 用户，但 ROS 进程以 `ubuntu` 用户运行，因此同步后必须修复文件所有权。
- `system_promt.txt` 的拼写错误需要被 `system_prompt.txt` 覆盖修正。
- 不要直接向 `/home/ubuntu/model/` 根目录放置 `prompts/` 子目录的完整副本，避免覆盖 `basic_cn.txt` 等未改动文件。
