# 标注上传后的九格检测头训练

更新日期：2026-10-08。当前主路线为冻结九格视觉编码器、训练 FCOS 检测头。

完整且与已恢复实例一致的命令见 [新实例恢复与九格采集训练](新实例恢复与九格采集训练_20261008.md)：

1. 第 2 节：检查数据盘，source `cloud_env.sh` 初始化每个新终端。
2. 第 4 节：上传人工复核 JSONL，核对云端原图与标签路径。
3. 第 5 节：选择完整飞行作为验证/测试，生成新数据集并训练 8 轮。
4. 第 6 节：读取最佳 head，验证集选阈值，独立测试集评估，再复制系统盘部署。
5. 第 7 节：将 head、数据划分、指标和日志备份到本地。

训练使用 `fcos_grounding.py train`，不使用历史 `fm9g_grounding.py train` 的 LoRA 参数。每轮产生 `epoch-XX/head.safetensors`；最佳检测头由 `best.json` 记录，完成标志为 `DETECTOR_TRAIN_FINISHED`。当前脚本不支持旧 head 续训或优化器断点恢复。
